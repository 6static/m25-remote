M25 remote enclosure

Stackable 50 x 50 mm modules for trying out button layouts. Every module shares the same joint, so you stack them in any order and turn each one in 90° steps.

Scroll to print each part from the bed up. Hit Rotate to turn it in 3D.

Example stacks

Each one checked for overlaps between parts, button bodies, the joystick and the ESP32. In 3D the button bodies and joystick show in red, the ESP32 envelope in green.

Generated with CadQuery from enclosure/enclosure.py. PETG, 0.2 mm layers, no supports.
